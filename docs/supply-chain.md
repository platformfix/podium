# Supply chain security

## Provenance and signing

Every image push gets a signed build provenance attestation, generated by GitHub's own Sigstore-backed [artifact attestations](https://docs.github.com/en/actions/security-guides/using-artifact-attestations-to-establish-provenance-for-builds), not a manually maintained signature. Verify any tag with the GitHub CLI:

```bash
gh attestation verify oci://ghcr.io/platformfix/podium:latest --owner platformfix
```

Helm chart releases get the same treatment: every chart version is attested too, not just the image.

## Software bill of materials

An SPDX SBOM is generated and attested the same way, pinned to the exact image digest rather than a floating tag. Download it for offline inspection:

```bash
gh attestation download oci://ghcr.io/platformfix/podium:latest --owner platformfix
```

## Scorecard and Artifact Hub

The repo runs an [OpenSSF Scorecard](https://scorecard.dev/) check on every push (see the badge on the main [README](../README.md)), and the Helm chart repo carries the metadata [Artifact Hub](https://artifacthub.io/) needs to list it (not yet claimed there).
